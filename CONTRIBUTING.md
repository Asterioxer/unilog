# Contributing to unilog

Thank you for your interest in contributing to `unilog`!

Please see our detailed [Contributing Guide](docs/contributing.md) for instructions on:
- Local development environment setup with `uv` and `npm`.
- Running linting, type-checking, and unit tests (`uv run ruff`, `uv run mypy`, `uv run pytest`, `npm run lint`, `npm run test:cov`).
- Code standards and semantic commit guidelines.

Thank you for helping build a better operational log intelligence platform!
